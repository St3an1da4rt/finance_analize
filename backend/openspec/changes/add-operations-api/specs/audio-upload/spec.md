## ADDED Requirements

### Requirement: Загрузка аудио через POST
Система SHALL предоставлять ручку `POST /audio`, принимающую аудиофайл в поле `file` запроса `multipart/form-data`, сохраняющую файл и создающую операцию со статусом `pending`.

#### Scenario: Успешная загрузка
- **WHEN** клиент отправляет `POST /audio` с файлом `audio/ogg` допустимого размера
- **THEN** система отвечает `201` и возвращает созданную операцию с `id`, `status=pending` и `category=uncategorized`

#### Scenario: Файл не передан
- **WHEN** клиент отправляет `POST /audio` без поля `file`
- **THEN** система отвечает `422`

### Requirement: Валидация аудио
Система SHALL принимать только аудио типов `audio/ogg`, `audio/mpeg`, `audio/mp4`, `audio/wav` размером не более настроенного лимита (по умолчанию 25 МБ).

#### Scenario: Недопустимый тип
- **WHEN** клиент загружает файл с типом `image/png` на `POST /audio`
- **THEN** система отвечает `415` и не сохраняет файл и операцию

#### Scenario: Превышен размер
- **WHEN** клиент загружает аудио больше лимита
- **THEN** система отвечает `413` и не сохраняет файл и операцию
