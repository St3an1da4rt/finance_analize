## Why

Бэкенд финансового трекера пока пустой (только каркас FastAPI). Пользователю нужны три сценария: загрузить изображение (например, чек), загрузить голосовое сообщение и посмотреть список своих операций постранично. Операции получают группу (перевод, зарплата и т.д.), поэтому модель операции должна её хранить.

## What Changes

- Новая HTTP-ручка `POST /images` — приём изображения (multipart/form-data), сохранение файла и создание операции в статусе `pending`.
- Новая HTTP-ручка `POST /audio` — приём голосового (multipart/form-data), сохранение файла и создание операции в статусе `pending`.
- Новая HTTP-ручка `GET /operations` — список операций с пагинацией (`limit`/`offset`), в ответе есть группа операции.
- Модель `Operation` с полем `category` (перевод, зарплата, другие категории; по умолчанию `uncategorized`) и ссылкой на загруженный файл.
- Распознавание содержимого (OCR / speech-to-text) и автоматическое проставление групп — **вне рамок** этого изменения; ручки лишь принимают и сохраняют данные и отдают операции с текущей группой.

## Capabilities

### New Capabilities
- `image-upload`: приём изображения через POST, валидация типа и размера, сохранение, создание операции.
- `audio-upload`: приём аудио через POST, валидация типа и размера, сохранение, создание операции.
- `operations-list`: получение операций с пагинацией; операции содержат группу (category).
