## ADDED Requirements

### Requirement: Загрузка изображения через POST
Система SHALL предоставлять ручку `POST /images`, принимающую изображение в поле `file` запроса `multipart/form-data`, сохраняющую файл и создающую операцию со статусом `pending`.

#### Scenario: Успешная загрузка
- **WHEN** клиент отправляет `POST /images` с файлом `image/jpeg` допустимого размера
- **THEN** система отвечает `201` и возвращает созданную операцию с `id`, `status=pending` и `category=uncategorized`

#### Scenario: Файл не передан
- **WHEN** клиент отправляет `POST /images` без поля `file`
- **THEN** система отвечает `422`

### Requirement: Валидация изображения
Система SHALL принимать только изображения типов `image/jpeg`, `image/png`, `image/webp` размером не более настроенного лимита (по умолчанию 10 МБ).

#### Scenario: Недопустимый тип
- **WHEN** клиент загружает файл с типом `application/pdf` на `POST /images`
- **THEN** система отвечает `415` и не сохраняет файл и операцию

#### Scenario: Превышен размер
- **WHEN** клиент загружает изображение больше лимита
- **THEN** система отвечает `413` и не сохраняет файл и операцию
